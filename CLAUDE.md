# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Проєкт

Лендинг на **Astro** з анімаціями на **GSAP**. Макет: Figma `DKUYT30DgwalJbcakhyLCt` (сторінка `0:1`, UI kit `135:984`; UI kit може бути неточним, звіряйся з макетом).

## Команди

- `npm run dev`: dev-сервер (http://localhost:4321)
- `npm run build`: збірка в `dist/`
- `npm run preview`: перегляд збірки
- `npx astro check`: перевірка типів

## Архітектура

- `src/pages/index.astro` лише збирає секції по порядку. Розмітки секцій тут немає.
- `src/components/sections/`: кожна секція в окремому компоненті (`Hero.astro`, `Features.astro`…). Дрібні елементи, що повторюються, кладемо в `src/components/ui/`.
- `src/content/`: **усі тексти** (JSON/MD/TS) і посилання на зображення. Жодного хардкоду тексту в компонентах: секція імпортує свій контент-файл або отримує дані через props.
- `src/assets/images/`: зображення. Їх підключаємо через `astro:assets` (`<Image />`), шлях беремо з контент-файлу.
- `src/styles/variables.css`: CSS-змінні для кольорів (`--color-*`), шрифтів (`--font-*`, `--fs-*`) і відступів (`--space-*`). У компонентах не пишемо «сирих» значень, лише `var(--…)`.
- `src/styles/global.css`: reset і базові стилі. Шрифти в `fonts.css` (PP Altera Carve з `public/fonts/`, IBM Plex Mono через `@fontsource`). Усе підключається в `src/layouts/Layout.astro`.

## Стилі

- Mobile-first: базові стилі пишемо під мобільний, розширюємо через `@media (min-width: …)`. Десктоп від `1024px`, макети 375 і 1920 px.
- Стилі секції зберігаємо в `<style>` її компонента (scoped).

## Зображення з Figma

Ассет з `get_design_context` — це сирий файл заливки, без кропу, масштабу, повороту й віддзеркалення з макета. Тому:
- Спершу `get_screenshot` вузла: це еталон того, як зображення виглядає в макеті.
- Готовий файл має збігатися зі скріншотом за пропорціями і кадром. Не вгадуй `object-fit`: звір обидва варіанти (розтягнути на рамку / зберегти пропорції) з еталоном і візьми той, що збігається. Задумка дизайнера — це те, що видно в макеті.
- Фото людей і сцен ніколи не розтягуй і не сплющуй, навіть якщо в макеті воно розтягнуте: тоді обріж оригінал під рамку з тим самим змістом кадру. Виняток: логотип, у якого макет задає пропорції.
- Обрізай і повертай файл заздалегідь (sharp), щоб у CSS лишались тільки розміри рамки, без `object-fit`-хитрощів.
- Якщо дизайнер продублював у Figma оригінал без обрізки, ріж з нього і звір з еталоном.
- Новий кроп зберігай під новою назвою, бо інакше браузер покаже старий файл з кешу.

## GSAP

- Анімацію запускаємо в `<script>` того компонента, якому вона належить: `import { gsap } from 'gsap'`, плагіни (`ScrollTrigger`) реєструємо через `gsap.registerPlugin`.
- Елементи для анімації позначаємо `data-*` атрибутами, а не класами стилів.
- Поважаємо `prefers-reduced-motion` (`gsap.matchMedia()`).

## Стиль роботи

Пиши коротко: мінімум коду й коментарів, без зайвих абстракцій.
